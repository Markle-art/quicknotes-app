\# QuickNotes



QuickNotes is a simple browser-based note-taking app that lets users create, organize, search, and delete notes by category while keeping them saved in the browser.



\## Features



\- Add notes with Personal, Work, or Study categories

\- Validate empty notes

\- Validate notes longer than 200 characters

\- Display the note creation date and time

\- Delete individual notes

\- Search notes without case sensitivity

\- Save notes using localStorage

\- Display the correct note count

\- Responsive layout for smaller screens



\## How to Run Locally



1\. Clone or download this repository.

2\. Open the project folder.

3\. Open `index.html` in a web browser.



No build tools or external dependencies are required.
